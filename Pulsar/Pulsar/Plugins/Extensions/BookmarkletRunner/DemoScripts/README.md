# BookmarkletRunner DemoScripts

演示脚本目录。4 个 `.js` 均由 `Pulsar.csproj` 显式引用，构建时复制到输出目录 `Assets\Scripts\Demo\`——**移动、改名或增删文件必须同步 csproj**。

| 文件 | 场景 |
|---|---|
| `browser_demo.js` | 浏览器基础操作 |
| `form_fill_demo.js` | 表单填写 |
| `data_extract_demo.js` | 数据提取 |
| `link_traverse_demo.js` | 链接遍历 |

目录归属依据：openspec `2026-06-16-project-structure-cleanup`。
