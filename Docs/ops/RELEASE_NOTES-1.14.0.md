### 新功能

- **设置窗口支持「动态标签页」**：右键手势、槽位编辑等重配置界面不再挤在「通用」页里，改为按需打开的临时标签页（语义与 VS Code 预览标签一致——重复打开激活既有页、干净页离开自动回收、脏页保留并在关窗时统一提示保存）。「通用」页瘦身为总开关 + 入口按钮。
- **外观设置独立成页**：主题、渲染器风格、主题预设、语言集中到「外观」页；主题预设升级为带色块的网格选择，不再藏进折叠卡片。
- **槽位编辑改为标签页，不再弹模态窗**：新增槽位走「新建向导」，子动作编辑器改为可折叠的手风琴行（默认折叠，避免一屏展开的表单）。
- **插件使用详情「下钻」**：设置 → 分析页的插件统计行可整行点击或点「详情」，查看单个插件的执行次数 / 成功率 / 平均耗时 / 最近使用、近 7 天趋势柱状图、槽位分布、模式分布与针对性推荐。
- **轮盘支持键盘导航**：方向键选择槽位（含双键对角）、数字键 1-9 直达、PageUp/PageDown 翻页、Enter 执行。
- **进程选择器新增刷新按钮**：可重新枚举当前窗口列表，刷新时保留过滤词与已选项。
- **E2E 低干扰模式**（自动化/调试用）：可将设置窗口以不抢焦点方式打开、点击改走 UIA 通道，便于在其他全屏应用运行时做验证。

### 修复

- **设置页三处布局与配色缺陷**：使用分析页 Top-3 排名徽章序号不可见（accent 令牌在 WPF-UI 4.3.0 中不存在 + 本地属性压制触发器）；关于页/分析页卡片宽度不占满视图，且折叠任一卡片会带动所有卡片宽度跳变；折叠侧边栏后导航标签被上下拉伸、拉伸量随标题长度增长。
- **轮盘滚轮翻页在中心空白区不响应**：改为按布局矩形判定命中，中心死区可正常翻页，轮盘外区域交还页面滚动。
- **名称形式的图标不渲染字形**：配置里写图标名称（如 `ReportDocument`）时此前被当作纯文本渲染，现会先归一化为字形码位。
- **槽位参数与可执行路径不展开环境变量**：`%USERPROFILE%` / `%APPDATA%` 形式的路径此前静默失效，现全链路展开。
- **WPS 未安装 VBA 组件时静默失败**：现在会给出「安装 VBA for WPS 并开启信任访问」的明确指引，不再只是「宏没反应」。
- **切换标签时指示器偶尔没有动画**：布局事件掐断了在跑的动画，指示器会瞬移；同轮修复了由此派生的「先跳后滑」与动画取值崩溃。
- **槽位编辑页右侧内容被裁切**：模态时代遗留的固定最小尺寸（760px）在标签页宿主下超出可用宽度，状态徽标与图标选择器被静默裁掉。
- **新建槽位保存后误弹「未保存更改」**：保存改为立即落盘，并去掉多余的一次跳转，提示时机改为落盘成功后。
- **密码类型参数的占位文字与选择器提示重叠**，且选择器按钮的提示文字恒为「浏览」；现按意图区分进程 / 文件 / 密码的图标与文案。
- **子菜单左键只选中不执行**、子动作选择应用后图标空白、级联子轮盘缺少数字气泡标识、子动作配置改动不触发保存状态。

### 性能优化

- **本地化资源瘦身**：清理长期积累的孤儿键，中英双语资源各由 1166 键降至 951 键，减少无谓的资源加载。
- **轮盘交互调校**：悬停响应 300ms → 120ms、磁吸上限 120 → 400 px/s、翻页动画曲线改缓、手势外甩取消更灵敏。
- **轮盘面板与设置外壳代码拆分**：`MenuSession` 由 3609 行降至 2874 行，手势编排、子菜单过渡、看门狗各自独立，行为不变。

### 其他

- **内部模块更名：`PKI` → `Secret Fill`**。该功能实际是「DPAPI 加密凭据存储 + 队列化输入注入」，与公钥基础设施（证书/密钥对）无关，旧名属于语义错误。插件在菜单中显示的名称（AutoFill）与用法**完全不变**。
- **⚠️ 升级提示**：随本次更名，内置插件 ID 由 `com.pulsar.pki` 改为 `com.pulsar.secretfill`。Pulsar 会在启动时**自动迁移**你的配置（`Profiles.json` 的槽位绑定与 `PluginUsageStats.json` 的使用统计，历史执行记录完整保留），无需任何手动操作；迁移是幂等的，旧 ID 仍可被识别。**建议升级前备份 `%AppData%\Pulsar\Profiles.json`**。已保存的凭据按 GUID 关联，不受影响。
- **视觉主题重构**：采用「Code dark + run green」设计系统，深色配色整体调整（槽位底色、激活通道、危险操作 hover 色）。
- **版本说明**：本版直接自 v1.12.0 升级。CHANGELOG 中的 1.13.0 / 1.13.1 两个版本段此前仅记录在仓库中、未对外发布，其全部内容已包含在本版内。
- **已知限制**：安装包为未签名代码，首次运行会触发 SmartScreen 提示（选择「更多信息」→「仍要运行」即可）。
