## 关键坑（复用价值高）

1. **Wpf.Ui 4.3.0 ThemesDictionary 不含 Accent\* 键** —— 运行时靠 ApplicationAccentColorManager 注入；测试环境无 Application 会静默解析失败（DynamicResource 失败不报错，文字变透明/回退黑）。ButtonThemeContrastTests 的 BuildLightTheme 需补文档默认值（#0067C0 + White），与 ThemeService.ApplyAccent 的 fallback 值保持一致。
2. **XAML 注释不能放在标签属性列表中间**（RadialMenuWindow 编辑时踩过，需移到元素内容区）。
3. **静态资源作用域**：UserControl 若要脱离 Application 实例化（单元测试 `new SlotXxx()`），必须在自身 Resources 合并 Tokens.xaml，否则 StaticResource 抛 XamlParseException。
4. 浮动层（Tutorial 卡片/遮罩、VbaRunner 选择器）是固定浅色设计，不能用 Fluent 动态令牌（会随主题切换破坏对比度），应定义本地 StaticResource 令牌。

### 本轮关键坑（复用价值高，均已写入 Docs/design/UX_REFACTOR_PROPOSAL.md 第六节）

1. **令牌形状必须匹配用法**：旧 `Pulsar.Pad.*` 是四边等距 Thickness，而 90% 用法是单边（`0,0,8,0` ×44）。均匀 Thickness 表达不了单边间隙，这才是零引用的根因——不是"忘了用"，是"用不了"。
2. **刻度要看数据**：旧刻度 4/8/16/24/32 把第二高频的 12（89 次）跳过了，却给零需求的 32 留了档位。
3. **ControlTemplate 内的 StaticResource 在模板加载时立即解析**，与 Style Setter 的延迟解析不同。凡引用数值令牌的**样式字典**必须自带 Tokens.xaml 合并 —— 已为 ButtonStyles/ScrollViewerStyles/SlotStyles/TooltipStyles 补齐（否则 ButtonThemeContrastTests 3 个用例抛 XamlParseException）。
4. **分类应作用于吸附后的值**：`0,3,0,4` 按原值判为多轴组合，吸附成 `0,4,0,4` 后其实是合法 `Gap.Vertical.XS`。
5. **grep 令牌名会命中注释**：`Theme.Light.xaml` 里"已迁移至 Tokens.xaml"的说明文字被误读成合并声明，导致误判 Theme.* 为僵尸；实际 Theme.Accent/SlotTypeBrush*/SlotHealthBrush* 都从 **C#** 引用。审计"僵尸令牌"必须 XAML+C# 一起扫，并先剥 XML 注释。
6. **`git stash push --include-untracked` 会因 Temp 下脚本的 CRLF 报 fatal 而失败**，随后误执行 `pop` 会去动用户**此前遗留的 stash**（本仓库有两个：stash@{0} 4d3e8ea、stash@{1} 32ea858）。冲突中止后两个 stash 均保留未应用，但**此操作很危险，勿再使用**；要对比基线改用 `git worktree`。
