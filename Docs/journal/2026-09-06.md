**关键决策 / 坑**
- `TryTierAsync` 状态码守卫初版 `<200 or >=300` 会把 302 探测层一刀切掉——改为 `<200 or >=400`，302 放行给 redirect 层自行判定；REST/Atom 层收到 3xx 会因 body 解析失败自然降级。
- fake gateway 按「URL 片段」路由在镜像场景失效：镜像 URL 内嵌完整官方 URL，任何官方片段都匹配得到镜像请求。改为两段式路由：先 Host 精确匹配，再 PathAndQuery 片段匹配。
- GitHub Atom 条目 id 是 `tag:github.com,2008:https://...` 形式（tag: URI），`Uri.Segments` 解析不可靠，改 `/releases/tag/` 子串定位；`TryParseRedirectLocation` 同样要求该 marker，防 `https://example.com/other` 被误判为版本。
- xUnit1012：InlineData 传 null 需参数声明 `string?`。
- 教程完成页外链选择扩展 `TutorialStep` 模型（`LinkUrl`/`LinkTextKey`）而非新增 PrimaryAction 枚举值——不触碰 E2E 依赖的按钮流程。
