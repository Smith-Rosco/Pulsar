## Session (13:3x–13:5x · 设置页 UX 五项：1 真 bug + 3 改进 + 1 真 bug)

### ① slot 创建保存链修复（真 bug）
- **现象**：点「保存槽位」→ 跳回「自动化槽位」→ 弹「未保存更改」→ 点保存 → 又跳回动态 tab（实际已创建成功）。保存机制不流畅。
- **根因（证据链）**：`SettingsViewModel.CommitCreatedSlotFromTabAsync` 只调 `_slotEditor.CommitCreatedSlot()`（内存）+ `MarkDirty()`，**不落盘**；随后 `DiscardTransientPageAsync`（内部导航到 Slots）+ `OpenTransientPageAsync`（导航回实体 tab）**是两次导航**。第一次离开时 `IsTransient(当前页)` 已为 false（注册被移除）→ 命中 `SettingsShellViewModel:60-65` 的 `userInitiated && !sourceIsTransient` 分支 → 守卫弹「未保存更改」。
- **修复**：提交后立即 `await Save()`（落盘 → `ResetDirty()`），守卫后续全 no-op；删除多余跳转，只保留**单次**导航到实体编辑 tab；成功通知从"提交时"移到"落盘后"（消除假成功）。文件：`ViewModels/SettingsViewModel.cs`。

### ② 进程选择器加刷新按钮
- `ProcessPickerViewModel` 新增 `IsRefreshing` / `CanRefresh` / `RefreshCommand`（重枚举 `GetActiveWindowsAsync`，保留过滤词，按 ExePath+Title 还原选中）；XAML 搜索框右侧加按钮（刷新中换 `ProgressRing`，`ArrowClockwise24` 靠 `InverseBoolToVisibilityConverter` 隐藏）。新增 resx 键 `Dialog.ProcessPicker.Refresh`。

### ③ 外观页「主题预设」卡片取消折叠
- **用户澄清是外观页（Appearance）这张卡片**——该卡片实为「色块网格」；`设置→常规` 的「右键手势」卡片才是用户描述的「一个开关+一个按钮」。按澄清改外观页主题预设。
- **实现要点（坑）**：`Wpf.Ui.Controls.Card` 在 4.3.0 里**只有 Content/Footer，没有 Icon/Header**（查 `Wpf.Ui.xml` 确认），不能替代带图标的卡片外观。改用 `CardExpander IsExpanded="True" IsEnabled="False"` 锁死展开；`IsEnabled=False` 会向下继承灰化 → 正文 `ListBox` 必须显式 `IsEnabled="True"` 重新点亮。

### ④ 子动作行默认折叠

### ⑤ 密码字段 placeholder 重叠 + 选择器 tooltip 语义错（真 bug）
- **现象**：密码类型 slot 编辑页，密码字段 placeholder「两个叠在一起」；左侧打开密码选择器的按钮 tooltip 也不对。
- **根因＝WPF 属性优先级陷阱（不是布局问题）**：`SlotParameterFieldTemplate` 的 `Grid.Column="1"` 中 secret 分支有两个元素同格竞显 —— `ui:TextBox`（`PlaceholderText`）与 `Border`（`DisplayValue`）。TextBox **同时**带 (a) 标签上的**本地** `Visibility="{Binding IsBoolType, Converter=BoolToVisInverse}"` 与 (b) `Style` 内 `IsSecretSelector` 的 `DataTrigger`。**WPF DP 优先级：本地值 > Style Trigger** → (b) 永久失效 → TextBox 可见 ∧ Border 也可见 → 重叠。
- **修复**：删标签上的本地 `Visibility`，全部条件统一收进 `Style.Triggers`（`IsBoolType=True`→Collapsed、`IsSecretSelector=True`→Collapsed）+ `<Setter Value="Visible"/>` 兜底。**两份重复模板同改**：`SlotConfigurationDialogContent.xaml`（~129）、`AddSlotContent.xaml`（~194）。
- **选择器按钮语义化**：原硬编码 `FolderOpen16` + `Dialog.PluginSettings.Browse` → `SlotParameterEditorModels` 新增 `PickerButtonIcon`（Process→`WindowConsole20` / File→`FolderOpen16` / Secret→`Key24`）+ `PickerButtonTooltip`（按 `PickerIntent` 映射）；新增 3 对 resx 键 `Dialog.AddSlot.Pick{Process,File,Secret}`。
- **⭐ 新增静态守卫锁定缺陷类**：`SettingsLayoutGuardTests.No_element_declares_visibility_both_locally_and_in_its_own_style`（扫「本地 Visibility ∧ 自身 Style 内有 Visibility Setter」）。**做了证伪测试**：临时注回旧缺陷 → 守卫**如期失败**并精确报 `AddSlotContent.xaml:241`；还原后通过 → 守卫非「恒真」已证。
