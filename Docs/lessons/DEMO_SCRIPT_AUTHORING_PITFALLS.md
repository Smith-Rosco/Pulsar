# 脚本与演示资产杂项坑（bookmarklet 节奏 / 下载伪装 / 编码 / 参数展开）

> 2026-09-07 · 来源：`Docs/demo/lesson.md`（演示环境开发排障）§1/§3/§4/§6~§10 中与脚本编写直接相关的部分。
> 录屏/配音/分镜类制作经验不在此列，见原始文档与 `Documents\Pulsar\Demo\RECORDING-GUIDE.md`。

## 1. Bookmarklet 注入后立即返回——动作要拉开节奏

- **症状**：多步脚本点完，页面「结果瞬间出现」，看不出流程。
- **根因**：`BookmarkletRunner` 注入后立即返回，同步执行无过程感。
- **修复**：用 `setTimeout` 分步执行（如 0 / 400 / 900ms），每步都有可见状态变化。写脚本时把「每一步在页面上留下可见痕迹」当作交付要求之一。

## 2. blob 下载伪装 `.xls` 会触发 Chrome 确认条

- **症状**：`Blob` + HTML 表格伪装 `.xls` 下载时，Chrome 偶尔弹「此文件类型可能有害」确认条，流程多一次点击。
- **根因**：Chrome 对部分来自 blob/file:// 的文档类扩展名走启发式告警。
- **修复**：改用 **CSV + UTF-8 BOM**（`\ufeff` 前缀），Excel 双击即开、中文不乱码、从不触发告警；文件名带业务语义（如 `经营报表_YYYYMM.csv`）。

## 3. Pulsar 槽位参数不做环境变量展开

- **症状**：槽位参数里写 `%USERPROFILE%\...\file.xlsx`，执行时找不到文件。
- **根因**：Pulsar 槽位参数按字面量处理，`%VAR%` 不展开。
- **修复**：配置注入脚本先把 `%USERPROFILE%` 替换为绝对路径；写文档/示例时提醒用户直接填绝对路径。

## 4. HTML 资产被写成乱码（mojibake）静默传播

- **症状**：页面打开全是 `鐧诲綍鎴愬姛` 类乱码，且多个页面 `<title>` 集体错误。
- **根因**：文件被按错误编码读写（GBK 内容当 UTF-8 保存 / 双重编码），且从别的页面复制后只改文件名没改内容，坏字节被静默传播。
- **修复**：HTML 一律 **UTF-8 无 BOM** + `<meta charset="UTF-8">`；任何资产改动后**回读中文内容自检**；复制文件后逐页核对内容。

## 5. 重构目标页必须保住脚本 DOM 契约

- **症状**：改版页面后注入脚本全部失灵。
- **根因**：脚本靠固定选择器与键序工作，换皮不改约定就断。
- **修复**：重构前先列出契约清单（选择器、TAB 焦点链、Enter 行为、`id` 列表），重构后 grep 逐项回验。

## 6. 演示/测试数据脚本要「可复现且不伤布局探测」

- **症状**：演示数据手工造，改一次脚本全变；或生成的「脏数据」干扰依赖布局的自动化。
- **修复**：演示数据用生成脚本（如 `gen-report-data.py`）确定性产出；只涂填充/字体色等**不影响值与布局**的维度做「脏」，保证布局探测类脚本不受干扰。
