# Switch Windows

> Scenario: you hop between five or six windows all day, wearing out Alt+Tab. Goal: give every frequent window a fixed direction on the radial menu.

## Switch Mode: `Ctrl+Q`

Pulsar has two menu modes:

| Mode | Hotkey | Purpose |
| :--- | :--- | :--- |
| Command mode | `Ctrl+Shift+Q` | Trigger macros, scripts, secure fill |
| **Switch mode** | `Ctrl+Q` | **Fast window switching** |

Press `Ctrl+Q` — each direction maps to an app:

![Window switch submenu](../../media/release/04-window-switch-menu.png)

Flick toward the target app and release — you're there.

## Add a Switch Target

1. Settings → Switch Mode page;
2. Create a slot and pick the target app (from running windows, or by program path);
3. Assign a fixed direction.

## App Not Running? Pulsar Starts It

Switch slots support "**launch if not running**": when the target app isn't running, flicking toward it starts and focuses it. Put your daily apps (OA client, Excel, browser) on the switch wheel and pull them all up with one key after boot.

## Tips

- **Muscle memory**: directions are fixed — a few repetitions and you switch blindfolded. That's the radial menu's edge over list menus; don't reshuffle directions often;
- **Submenus**: too many apps? Group them into cascading submenus (Office / Browsers / Chat) and keep the main wheel for high-frequency items;
- **Combine modes**: `Ctrl+Q` to jump to the app, then `Ctrl+Shift+Q` to run its action — two flicks per complete task.
