# 我要跑宏（Excel/WPS）

> 场景：每天在 Excel/WPS 里重复制表、整理数据。目标：把常用宏变成轮盘上的一个动作，一点即跑。

## 前置条件

- 已安装并完成首次运行（见[上一章](01-install-and-first-run.md)）；
- Excel 或 WPS 已安装；
- 你已有一个保存好的 VBA 宏（或者想边做边学）。

## 第一步：打开「Excel 宏执行器」插件设置

1. 打开 Pulsar 设置 → 插件；
2. 找到 **Excel 宏执行器**（Excel Macros），进入其动作配置。

## 第二步：把宏绑到一个槽位上

1. 新建一个槽位（Slot），动作类型选择「运行 Excel 宏」；
2. 填写：
   - **宏名称**：你在 Excel/WPS 里保存的宏名（如 `月度报表`）；
   - **目标工作簿**（可选）：指定在哪个工作簿中执行；
3. 把槽位放到轮盘的某个**方位**上——建议放在你顺手的方向（如右侧）。

## 第三步：一键执行

1. 打开你的 Excel/WPS 工作簿；
2. 按 `Ctrl+Shift+Q` 唤出轮盘；
3. 朝宏所在方向滑动、松开：

![Excel 跑宏瞬间](../../media/release/03-excel-macro-moment.png)

4. 宏在目标工作簿中自动执行完毕。

## 小技巧

- **宏会记录到多个工作簿？** 不用复制粘贴宏代码——Pulsar 直接调用目标工作簿里的宏；
- **配合级联子菜单**：动作多的时候可以把同类宏收进子菜单（扇形展开），保持轮盘清爽；
- **第一次没跑通？** 先在 Excel 里手动跑一次确认宏本身可用，再回来检查宏名拼写（区分大小写）。
