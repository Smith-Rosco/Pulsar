# 常见问题（FAQ）

## 安装与启动

### 双击安装包提示「Windows 已保护你的电脑」

Pulsar 目前未购买代码签名证书，SmartScreen 会拦截未签名程序。点击 **更多信息** → **仍要运行** 即可。如仍有顾虑，请先核对 [SHA256](#如何校验下载文件的-sha256)。

### 安装需要管理员权限吗？

安装版需要（写入 Program Files）。独立版（zip 解压）不需要管理员权限，适合公司管控电脑。

### 我的双击没反应 / 启动后托盘没有图标？

1. 独立版请确认解压到了**固定文件夹**（不要从压缩包内直接运行）；
2. 检查是否被杀毒软件拦截（查看隔离区并加白名单）；
3. Pulsar 启动后缩在系统托盘（右下角），点托盘小图标呼出菜单。

### 卸载会丢配置吗？

不会。配置与凭据保存在 `%AppData%\Pulsar`，卸载默认保留（卸载界面明示）。重新安装后自动继承。

## 使用

### 忘记热键 / 想改热键？

默认：`Ctrl+Shift+Q` 命令模式，`Ctrl+Q` 切换模式。设置 → 热键 中可修改。

### 滑动方向总触发错误的动作？

方位是固定的——去设置里核对槽位方位，建议为高频动作锁定固定方位并保持稳定，形成肌肉记忆。

### 宏执行报错？

1. 先在 Excel/WPS 里手动运行该宏，确认宏本身可用；
2. 核对 Pulsar 中填写的宏名与实际宏名完全一致（区分大小写）；
3. 若是 WPS，确认已安装 VBA 环境且工作簿为可启用宏格式（`.xlsm`）。

### 网页脚本没生效？

1. 确认目标是当前**前台**窗口且页面已加载完成；
2. 老旧系统页面结构各异，脚本需按目标页面实际 DOM 调整（先从示例库改起）；
3. 部分内网页面嵌在框架（frame）中，脚本需定位到正确 frame。

## 安全与隐私

### Pulsar 会联网吗？

核心功能完全本地运行。当前版本仅在「关于」页手动检查更新时访问 GitHub 相关主机，不上传任何本机信息；可在设置中关闭自动检查。

### 密码是怎么保存的？

使用 Windows DPAPI（当前 Windows 用户 + 机器绑定）加密存储在本机 `%AppData%\Pulsar`，明文只在你触发注入的一瞬间出现且全程在屏幕上可见的登录页内完成。

## 其他

### 如何校验下载文件的 SHA256？

对照 Release 附带的 SHA256 清单，在 PowerShell 中执行：

```powershell
Get-FileHash .\Pulsar-v1.10.0-Setup.exe -Algorithm SHA256
```

输出与清单一致即为原版文件。

### 界面能换英文吗？

可以。设置 → 语言：简体中文 / English 随时切换。
