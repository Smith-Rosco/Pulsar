# 我要登旧系统（安全填表与网页脚本）

> 场景：好几个内网系统要反复登录；老旧网页不支持浏览器插件/油猴；同一份表单一天填八遍。目标：把这些全部变成轮盘上的一键动作。

Pulsar 有两件武器对付老旧系统：

| 武器 | 适用场景 | 背后插件 |
| :--- | :--- | :--- |
| 🔐 **安全填表登录** | 账号密码登录、表单填充、自动提交 | 秘密填充（PkiPlugin） |
| 🌐 **网页脚本** | 老旧内网页面的定制自动化操作 | 网页脚本执行器（BookmarkletRunner） |

## 一、安全填表登录

### 1. 保存一条凭据

1. 打开 Pulsar 设置 → **秘密填充**（Secret Fill）；
2. 新建凭据：填写标签（如「OA 系统」）、账号、密码；
3. 密码使用 **Windows DPAPI 加密**保存在你本机——不落明文、不上传。

### 2. 绑定登录动作

1. 新建槽位，动作类型选择「秘密填充」；
2. 配置目标字段映射：账号填到哪个输入框、密码填到哪个输入框、是否自动点击登录按钮；
3. 保存到轮盘某个方位。

### 3. 一键登录

在目标系统页面按 `Ctrl+Shift+Q`，朝凭据方向滑动、松开——账号密码自动注入、自动提交。

> 🔒 安全说明：凭据加密存储于本机，注入过程直接发生在你屏幕上可见的登录页；Pulsar 不联网传输任何凭据。

## 二、老旧网页脚本

很多公司内网系统年代久远，装不了油猴、装不了浏览器扩展。Pulsar 从桌面层注入脚本，绕开这些限制。

### 1. 从示例库起步（推荐）

不会写脚本？设置 → **示例库**里有现成的网页脚本示例，选择贴近你场景的示例一键复制。

### 2. 创建自己的网页脚本动作

1. 设置 → 插件 → **网页脚本执行器**（Web Scripts）；
2. 新建动作，把为该网页定制的脚本粘进去；
3. 绑定到轮盘方位。

### 3. 执行

打开目标内网页面 → `Ctrl+Shift+Q` → 朝脚本方向滑动松开。重复录入、翻页、导出这类动作从此一键完成。

## 典型组合：登录 + 录入一条龙

把「OA 登录」（秘密填充）和「OA 日报录入」（网页脚本）放在相邻方位，每天上班：呼出轮盘 → 滑登录 → 呼出 → 滑录入，两个动作完成以往十分钟的重复操作。
