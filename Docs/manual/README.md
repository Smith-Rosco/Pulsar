- 手册随版本发布走：发布前按 `Docs/ops/RELEASE_CHECKLIST.md` 核对手册链接有效性。
- 手册叙事遵循重定位口径（自动化领衔 / 凭据护城河 / 窗口打底），不窄化为「启动器」。
