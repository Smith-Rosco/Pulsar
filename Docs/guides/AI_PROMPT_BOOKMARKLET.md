# AI 脚本编写提示词 — 书签脚本（BookmarkletRunner / 老旧网页自动化）

> 用途：把下面的提示词整段粘给任意 AI，再补上你的需求与页面信息，即可得到一个能被 Pulsar「网页脚本执行器」注入老旧内网页面运行的 `.js` 脚本。
> 参考：[BookmarkletRunner 插件文档](../Plugins/BookmarkletRunner.md)、
> [lessons/DEMO_SCRIPT_AUTHORING_PITFALLS.md](../lessons/DEMO_SCRIPT_AUTHORING_PITFALLS.md)（排障实录）。
> 范本：`Pulsar/Pulsar/Plugins/Extensions/BookmarkletRunner/DemoScripts/`。

---

## 提示词（整段复制，替换【需求】【页面信息】后发给 AI）

```text
你是资深前端工程师。请为我编写一个将在 Pulsar BookmarkletRunner 插件中
执行的 .js 书签脚本，目标是公司老旧内网页面（也可能是 file:// 本地页）。

【需求】<描述要在页面上自动完成的流程，例如：填用户名密码 → 点查询 → 导出报表>

【页面信息】
<关键元素的选择器/id：输入框、按钮、表格、状态区域等；无法提供就写"未知"，
并要求脚本优先按 id 探测、找不到时在页面上给出可见提示>

【硬性约束】
1. 单文件自包含 IIFE：(function () { ... })(); 现代多行格式即可，
   插件会用 NUglify 校验语法并压缩成单行注入。禁止外部依赖：
   不 fetch 远程脚本/库、不 import、不假设 jQuery 存在。
2. 执行环境是老旧内网页，不要假设现代 API 全部可用；优先原生 DOM 方法；
   兼容 Chrome / Edge。
3. 多步流程必须用 setTimeout 分步（建议 0 / 400 / 900ms 量级的节奏），
   每一步都在页面上留下可见状态变化（徽标变色、状态栏大字、操作日志面板、
   按钮划线等）。原因：脚本注入后执行器立即返回，同步一把梭在视觉上等于
   "瞬间完成"，既看不出流程、也无法判断执行到哪一步失败了。
4. 选择器只依赖 id / 稳定结构，不依赖动态生成的 class；
   对找不到的元素要在页面状态区报出"哪一步、缺什么"。
5. 需要产出文件时用 CSV + UTF-8 BOM（内容前加 \ufeff，Excel 双击即开、
   中文不乱码），禁止用 Blob + HTML 表格伪装 .xls——Chrome 会弹
   "此文件类型可能有害"确认条打断流程。
6. 不修改全局对象、不覆盖页面已有函数；把页面取出的数据写入 DOM 前做好
   转义（textContent 优先于 innerHTML）；脚本要幂等，可重复执行。
7. 注意页面编码：老旧内网页可能是 GBK，若注入的中文提示显示乱码，
   在交付说明里注明可改英文提示或与页面编码一致。

【交付要求】
- 完整 .js 文件内容（一个代码块给全）；
- 附一份「DOM 契约清单」：脚本依赖的全部选择器、TAB 焦点链、
  Enter 提交行为、id 列表——页面日后改版时按清单逐项回验；
- 附 3~5 条人工验证步骤。
```

---

## 使用提示

1. 脚本保存为 `.js`，在 Pulsar 槽位里填**绝对路径**（槽位参数不做环境变量展开）。
2. 页面改版/换肤后脚本失灵，第一件事是对照 AI 交付的「DOM 契约清单」逐项回验选择器。
3. 若流程涉及自动登录，账号密码建议改用 Pulsar 的「秘密填充」（系统级加密注入），不要把明文写进脚本。
