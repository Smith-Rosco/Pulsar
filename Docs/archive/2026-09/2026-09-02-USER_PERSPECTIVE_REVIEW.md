# Pulsar 用户视角评测报告

> **评测视角**：以一名普通 Windows 重度用户的身份，沿着「发现 → 安装 → 上手 → 日常使用 → 出问题时」的完整旅程评价 v1.8.x。
> **评测范围**：产品体验，不评代码实现。依据：README、CHANGELOG、Artifacts 发布包、Docs 文档体系、Docs/roadmap 与 StarPie 对比。
> **日期**：2026-09-02

---

## 一、总评

**一句话：这是一台为"肌肉记忆 + AI 协作"打造的高性能引擎，但它的车漆、说明书和 4S 店还没准备好。**

| 维度 | 得分 | 一句话理由 |
|---|:---:|---|
| 产品定位 | 8.5 | 空间定位替代 Alt-Tab 是真实痛点，PKI 注入是稀缺差异化 |
| 日常使用 | 8.0 | 双模式热键 + MRU 中心 + 未运行自启动，高频路径顺畅 |
| 可靠性 | 8.5 | 断路器 + Toast 通知 + 330+ 测试，插件崩了不拖垮主程序 |
| 安全隐私 | 8.0 | DPAPI 加密、元数据/密文分离、外部插件权限门控 |
| 功能广度 | 7.0 | 6 个内置插件覆盖面够用，但子菜单/手势细节落后竞品 |
| 文档社区 | 6.5 | 开发者文档一流，用户文档几乎为零，CHANGELOG 空白 |
| 上手体验 | 6.0 | 有交互式教程加分，但分发形态和第一印象拖后腿 |
| 视觉定制 | 5.0 | 仅 Dark/Light 两主题、无自定义图标库，roadmap 自认落后 |
| **综合** | **7.2** | **"工程强、产品弱"——离好产品只差一层包装和打磨** |

## 二、真正打动用户的点

1. **空间定位是真的省力。** Slot 位置固定不随使用频率重排（这是刻意设计），用一周后确实可以"盲操"。切换模式把 MRU 窗口放圆心，回到上一个应用只要一次按键，这个细节很懂人。
2. **PKI 凭据注入解决的是真问题。** 不用切窗口、不用密码管理器复制粘贴，热键唤起 → 选中扇区 → 凭据自动打进当前窗口。"焦点回旋镖"保证注入后焦点回到原窗口，思路成熟。
3. **VBA 执行器是精准打击。** 在 Excel/WPS 里一键跑宏，对国内办公场景是很多国际启动器不会做的功能。
4. **出问题时用户不会被"摔死"。** 扩展插件崩溃走断路器（1 分钟 3 次崩 → 禁用 60 秒 → 半开重试），并弹 Windows 通知告知；核心插件崩溃才致命。用户感知是"坏了一个零件"而不是"整车趴窝"。
5. **窗口切换的可控性。** 黑名单 + Window Inspector 生成的排除/放行规则，对多显示器、多窗口重度用户很友好。
6. **双语完整支持**（zh-CN / en），插件元数据还能按约定自动本地化。

## 三、按用户旅程排的痛点

### 阶段 1：发现（决定 3 秒内的生死）⚠️ 最大短板

- **README 的截图全部是占位符，演示视频是占位链接。** 用户打开 GitHub 首页，看不到产品长什么样——对一个以"视觉空间记忆"为核心卖点的产品，这是致命的。用户无法被一张徽章墙说服。
- 项目根目录明明躺着 demo 录像（`export-*.mp4`），却没有进入 README。

### 阶段 2：安装

- **只有 zip，没有安装器**（无 MSI/Setup，无开机自启引导，无卸载入口）。full 包 83.7MB（自包含）与 portable 包 8.8MB 的适用差异，下载页没有任何解释文案。
- **无自动更新机制**，用户需要自己盯 Releases。
- 分发的 exe 未签名（zip 直发基本可以断定），Windows SmartScreen 会弹"已保护你的电脑"——对普通用户是劝退点。

### 阶段 3：上手

- 交互式入门引导（`Features/Tutorial`）是实打实的加分项。
- **默认热键 Ctrl+Q 与 Chrome 的"退出"等常见快捷键冲突**。全局热键会拦掉应用内的同名快捷键，首次运行缺少冲突检测/提示，用户会困惑"浏览器怎么按 Ctrl+Q 没反应了"。

### 阶段 4：日常使用

- 顺畅（见第二节）。唯一的预期管理问题：**UI 自动化注入类插件（PKI、书签执行器）天然受目标应用 UI 变化影响**，某天目标软件更新后可能失效——需要兼容性说明，否则用户会当成"Pulsar 坏了"。

### 阶段 5：出问题时

- **没有面向用户的任何东西**：无用户手册、无 FAQ、无故障排查页。Docs/ 里 118 个文件几乎全部面向开发者（架构、ADR、lessons）。
- **CHANGELOG 实质空白**：v1.8.0 的条目全是 TODO，Unreleased 也是"暂无"。用户无法判断要不要升级。
- **版本号不一致**：README 徽章写 v1.8.0，Artifacts 里是 `Pulsar-1.8.1-*.zip`。小问题，但很伤可信度。

## 五、结语

Pulsar 的**内核已经是一流水平**：架构纪律（不可变上下文、断路器、权限门控）、测试覆盖、以及 roadmap 中对自己与 StarPie 差距的清醒认知，都超过绝大多数个人项目。

但从用户视角看，它现在像一间**精装修但没挂招牌的店**：路过的用户看不到橱窗（截图/视频）、进门没有向导（用户手册）、结账没有小票（CHANGELOG）。这些都不是难事——第三、四节的 1-3 号改进合计不到一天工作量，却能把第一印象从"看不懂"拉到"想试试"。

**建议的优先级**：先完成 1-3 号快改，再做用户手册；视觉定制按 roadmap 中期推进。内核不必大动。
