# Demo 视频脚本（三支 · 30–60s · 录屏）

> 对应 change `2026-09-05-repositioning-narrative-rollout` task 3.1。录屏产出 mp4 后入本目录（`Docs/media/release/videos/`）。
> 统一要求：全程 Dark 主题 1920×1080；口播语速 ≈ 每秒 4.5 字；每支片尾同一收尾卡（品牌字标 + 「GitHub 搜索 Smith-Rosco/Pulsar」）。

---

## 脚本一：《一键跑宏》（Excel 跑宏 · 40s）

**叙事线**：重复制表 → 一键动作的转化瞬间。

| 分镜 | 时长 | 画面（录屏内容） | 口播台词 |
| :--- | :--- | :--- | :--- |
| S1 | 0–6s | Excel 报表页，手动重复操作（复制→粘贴→求和）快速播放 | 每天打开 Excel，第一件事是不是又是这几步？ |
| S2 | 6–12s | 切出：按 `Ctrl+Shift+Q`，轮盘在鼠标旁展开（素材 03-excel-macro-moment 姿态） | 把你保存好的宏，放进轮盘的一个方位——以后它就是一个动作。 |
| S3 | 12–20s | 高亮宏槽位，滑动松开，镜头留在 Excel：宏自动执行，数据瞬间成型 | 滑一下，松开——宏自动跑完，报表直接成型。 |
| S4 | 20–30s | 演示 WPS 同样可用（打开 WPS 表格，重复 S3） | Excel 和 WPS 都一样。宏还是那个宏，只是不用再翻菜单。 |
| S5 | 30–38s | 设置页展示「运行 Excel 宏」动作配置三要素：宏名 / 目标工作簿 / 方位 | 配置只要三步：宏名、工作簿、方位。你的肌肉记忆，就是快捷键。 |
| S6 | 38–40s | 收尾卡 | Pulsar——把重复，变成一滑。 |

## 脚本二：《驯服老旧系统》（网页脚本注入 · 45s）

**叙事线**：油猴装不上的内网老系统 → 桌面层脚本一键化。

| 分镜 | 时长 | 画面（录屏内容） | 口播台词 |
| :--- | :--- | :--- | :--- |
| S1 | 0–8s | 老旧内网页面（复用 browser_demo 示例页），手动点击：查报表 → 选日期 → 点查询 → 导出 | 公司内网系统十年没升级，插件装不上、油猴不生效——但活还是你的。 |
| S2 | 8–16s | 展示「网页脚本执行器」动作：粘贴为该页面定制的脚本（示例库脚本特写） | Pulsar 从桌面层注入脚本：给这个页面写一段脚本，绑到轮盘上。 |
| S3 | 16–28s | 呼出轮盘 → 滑向「日报录入」→ 脚本自动完成选日期、填数据、点查询全流程 | 以后做这件事：呼出、滑动、松开。三秒，流程跑完。 |
| S4 | 28–38s | 连续演示第二个脚本动作（数据导出），强调方位固定、闭眼可操作 | 页面再老，动作永远在那个方位。练两次，闭着眼都能操作。 |
| S5 | 38–43s | 示例库画面：五六个现成网页脚本示例 | 不会写脚本？示例库现成的改一改就能用。 |
| S6 | 43–45s | 收尾卡 | Pulsar——驯服你的老旧办公系统。 |

## 脚本三：《登录，只要一滑》（安全填表自动化 · 40s）

**叙事线**：多个系统反复登录 → 凭据护城河的安全感。

| 分镜 | 时长 | 画面（录屏内容） | 口播台词 |
| :--- | :--- | :--- | :--- |
| S1 | 0–8s | 快切三个登录页（OA / 邮箱 / 报销系统），每次都手动输账号密码 | 一天登录几个系统？输几次密码？ |
| S2 | 8–14s | 设置页展示凭据列表；特写「DPAPI 加密存储」说明文案 | 账号密码用 Windows 级加密锁在你自己电脑里——不上传，不落明文。 |
| S3 | 14–24s | 打开 OA 登录页 → `Ctrl+Shift+Q` → 滑向「OA 登录」→ 自动注入、自动提交、进入系统 | 需要登录时：呼出、一滑。账号密码自动注入，自动提交。 |
| S4 | 24–32s | 连续滑两个不同系统登录（方位不同的凭据动作） | 每个系统一个方位。一天省下的，不止是时间。 |
| S5 | 32–38s | 安全口径画面：登录全程在屏幕上可见的页面内完成；Pulsar 不联网 | 注入发生在你眼前的登录页里，全程可见、全程本地。 |
| S6 | 38–40s | 收尾卡 | Pulsar——安全，也是一种效率。 |

## 制作约定

- 录屏走 E2E 管线可用 `Pulsar.E2E` recording 输出（`recording.mp4`），或 OBS 手录（`Ctrl+Shift+Q`/`Ctrl+Q` 热键需在录屏内可复现）；
- 口播可后期配音或 TTS；字幕使用与手册一致的叙事口径（一键跑宏 / 登旧系统 / 切窗口）；
- 产出命名：`demo-01-excel-macro.mp4` / `demo-02-legacy-web.mp4` / `demo-03-secure-signin.mp4`，入 `Docs/media/release/videos/`（如体积过大，视频不入 git、只入 Release 资产并在 README 链接）。
