# ADR-011 决策 6 修订草案：级联子环半径几何（Fan/Ring 位置问题）

> **状态**：DRAFT — 待用户 QA 截图确认现象后定稿（2026-09-05 QA 暂停点：Fan 方向缺陷已修复并重验通过，用户反馈「位置仍有问题」，具体现象留待下轮 QA 明确）。
> **范围**：仅 ADR-011 Decision 6 的 `SubMenuRingRadiusRatio=0.6` 参数口径及子环布局公式；不涉及分页语义（Decision 1–5、7、8 不动）。
> **作者**：MainAgent，2026-09-05（打游戏间隙推进，未启动真机、未跑 E2E）。
> **仲裁口径**：`cascade-submenu-layout` spec、ADR-011、`MenuSession.cs`、`SubMenuLayoutEngine.cs`。
> **现象更新（2026-09-05 晚，用户实测）**：用户补充「子 slot 沿父方向渲染（右下角），但鼠标在中心 slot 附近即触发」——这是**独立的命中缺陷**（`HitTestFan` 无角度扇区约束），已作为 QA change 3.4 单独修复（翼扇区约束），**不属于本 Amendment 的几何参数问题**；本草案继续覆盖「子项间距/与中心圆/根环槽位带的重叠」（F1–F5）。

## 1. 背景

Fan 方向几何缺陷修复（`de96482`）后，用户重验确认**子项可见、方向正确**（A1/A2 核心），但反馈「**位置仍有问题**」。本轮未获具体截图，因此先做纯几何量化，把当前参数下的客观重叠/间距事实钉死，作为下轮 QA 对照基线与 Amendment 论据。

## 2. 当前几何基线（纯计算，slotsPerPage=8）

参数链（`SlotLayoutEngine` + `MenuSession.BuildCascadeParentPose`）：

| 参数 | 值 | 来源 |
|---|---|---|
| 根环半径 | **90** DIP | `CalculateOptimalRadius(8,50)`：8 槽 minRadius=78.39 被 BaseRadius=90 托底 |
| 槽位尺寸 | 50×50 | `CalculateOptimalSlotSize(8)=50`（8 槽不缩放） |
| 中心圆 / 死区半径 | 35 | `CalculateOptimalCenterSize(8)=70` → 死区 `max(10, 70/2)` |
| 子环半径 | **54** DIP | `90 × SubMenuRingRadiusRatio(0.6)`（`maxSafeRadius=225` 不 clamp） |
| 窗口 / 中心 | 500×500 / (250,250) | `RadialMenuWindow.xaml` |

由此推出的**客观事实**（单位 DIP）：

| # | 事实 | 数值 | 结论 |
|---|---|---|---|
| F1 | Fan3 相邻翼中心距（翼角 ±30°/0°，半径 54） | `2·54·sin15° ≈ 27.95` | 槽位 50 → **重叠 22 DIP**，三个子项几乎叠成一团 ⚠️ 本轮最重要发现 |
| F2 | Fan2 翼中心距（夹角 60°） | `2·54·sin30° = 54` | 净空隙仅 **4 DIP**，两翼几乎贴住 |
| F3 | 子项内沿 vs 中心圆外沿 | 内沿 `54−25=29` < 外沿 `35` | **与中心圆重叠 6 DIP**（journal 已记录的「54 小环贴中心圆」） |
| F4 | 子环槽位带 vs 根环槽位带 | `[29,79]` vs `[65,115]` | **径向带重叠 14 DIP**（Ring 子项插进根环槽位带） |
| F5 | Ring5 相邻中心距（72° 均布） | `2·54·sin36° ≈ 63.5` | 净空隙 13.5 DIP，外接圆（35.4×2=70.7 > 63.5）相交 → 视觉拥挤 |

## 3. 根因：设计参数空间的约束矛盾

子环半径 r 要同时满足三个不重叠条件，但可行域为空：

| 约束 | 条件 | 需要 |
|---|---|---|
| Fan3 翼不互相重叠 | `2r·sin15° ≥ 50` | **r ≥ 96.6** |
| Fan2 翼不互相重叠 | `2r·sin30° ≥ 50` | r ≥ 50 |
| 不撞中心圆 | `r − 25 ≥ 35` | r ≥ 60 |
| 不撞根环槽位带（内侧方案） | `r + 25 ≤ 65` | r ≤ 40 |

- 「避开中心圆」与「避开根环槽位带（内侧）」**直接矛盾**：干净地带 `[35,65]` 仅 30 DIP 宽，装不下 50 DIP 槽位。
- **Fan3 需要 r ≥ 96.6，即必须放到根环（90）外侧**——当前 54 的几何下 Fan3 结构性无法不重叠。
- 根因是**单一子环半径 + 内侧比例 0.6** 同时服务于 Fan（≤3 翼，角度稀疏 30°~60°）与 Ring（≥4 子项，均布整圈）两种需求不同的队形，而 0.6 比例对两者都不合适。

## 4. 候选方案（数字 + 影响面）

| 方案 | 描述 | 关键数字 | 优点 | 风险/影响面 |
|---|---|---|---|---|
| **A（推荐）Fan 移到根环外侧** | Fan 子环半径改用根环外侧参数（如 `rootRadius + slotSize/2 + gap`，≈117~120）；Ring 暂不动或另行评估 | r=120：Fan3 翼距 `2·120·sin15°≈62.1` ✓；Fan2 120 ✓；子项内沿 95，远离中心圆 ✓；窗口安全（120+25=145 < 225）✓ | 符合「沿父方向向外展开」的直觉；Fan3 彻底不重叠；HitTestFan 用 `subRingRadius+slotSize/2` 自动适应；filler 留根环不受影响 | 改动 `BuildCascadeParentPose` 或 Fan 分支半径来源；`CascadeSubMenuLayoutRuntimeTests` 的 54 断言需更新；动画磁吸目标自动跟随 |
| **B Fan 内侧放大** | r 提到 60~65（0.67~0.72） | r=65：与中心圆 40>35 ✓ 脱离；Fan3 翼距 `2·65·sin15°≈33.7` 仍 <50 ⚠️ 重叠 16 | 改动最小（只改常量） | Fan3 仍重叠——**不能彻底解决问题**，除非同时缩子项槽位（槽位 ≤ 34 才够，UI 太小不可行） |
| **C Ring 也外侧化** | Ring 子环半径 = `rootRadius + slotSize`（140），槽位带 [115,165] 与根环带 [65,115] 正好相切 | Ring5 相邻距 `2·140·sin36°≈164.6` 极宽裕 ✓ | Ring 彻底摆脱拥挤 | 改动面最大；环形半径 140 视觉上偏大（窗口 500 内仍安全）；需评估 UX |

**推荐：方案 A 为主，Ring 是否同步调整取决于 QA 现象**——若用户截图显示 Ring5 拥挤/串台（F4/F5 相关），再叠加方案 C 或 Ring 独立参数；若仅 Fan 观感异常，A 单独即可。

## 5. 下轮 QA 截图指引（打完游戏后照此做，一次到位）

> **前提坑**：轮盘是**按住** `Ctrl+Shift+Q` 才显示、松手即消失，无法在按住的同时按截图快捷键。所以不直接用截图键，改用下面任一方案：

**方案一（推荐）：录屏抽帧**——先录、后抽，完全不抢按键。
1. `Win+Alt+R` 开始录屏（Win+G 游戏栏，或 Xbox Game Bar）。
2. 按住 `Ctrl+Shift+Q` 唤出轮盘 → 左键依次点开 `QA Fan-3` / `QA Fan-2` / `QA Ring-5`，每个队形保持 2~3 秒（期间按住不松）。
3. 松开 → `Win+Alt+R` 停止录屏。
4. 从录像里抽帧（打开 mp4 暂停到需要的画面，截图即可；或 `ffmpeg -i 录像.mp4 -ss <秒> -frames:v 1 out.png`）。

**方案二：截图工具延迟模式**——先按延迟、后唤出。
1. 打开「截图工具」（Snipping Tool）→ 点「延迟」选 **10 秒** → 点「新建」（开始倒计时，屏幕会提示）。
2. 倒计时内：按住 `Ctrl+Shift+Q` 唤出 → 点开目标队形 → **保持按住**直到自动截屏。

**方案三（最省事）：口头描述**——不需要像素证据，对照下表回答「是/否 + 大概间距」即可：
1. Fan3 三颗子项是**叠在一起**、还是明显分开？（对照 F1）
2. Fan2 两翼是**几乎贴住**、还是分得开？（对照 F2）
3. 子项是否**骑在中心圆**上？（对照 F3）
4. Ring5 子环是否与根环槽位**交错拥挤**？（对照 F4/F5）

重验时对以下四个现象（任选方案）各留一份证据：

1. **Fan3 整体**（QA Fan-3 展开）：三个子项是否叠在一起/彼此挤压 → 对应 F1
2. **Fan2 整体**（QA Fan-2 展开）：两翼是否几乎贴住、是否骑在中心圆上 → 对应 F2/F3
3. **Ring5 整体**（QA Ring-5 展开）：子环是否与根环槽位交错拥挤、子项是否贴中心圆 → 对应 F4/F5
4. **A4 标签**：任一队形下子项标签是否被切/溢出

对照表：截图现象 → 根因 → 拟用方案（A / C / 独立参数）。
