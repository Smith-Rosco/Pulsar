# QA Checklist — 级联子菜单 Fan 人工验收（任务 2.1–2.8）

> **一句话背景**：轮盘上某个格子（父格子）可以挂几个「子动作」，点开后会在它周围散开一排小格子。  
> 散开有两种队形：**Fan（扇形，最多 3 个，像一把展开的折扇）** 和 **Ring（小圆环，4 个以上时用）**。  
> 这一轮要验的就是：这两种队形在真机上**画得对不对、点得准不准**。  
> （这套东西一直只有单元测试，从没人真手点过，所以必须过一遍。）

真出问题时的仲裁口径：`cascade-submenu-layout` spec、`cascade-submenu-entry` spec、ADR-011。  
发现不对 → 记到文末 Change History，按 change 的 §3 走「修 + 补回归测试」。

## 准备（PowerShell，照抄即可）

> **为什么必须用真实配置的正常实例**：轮盘的全部鼠标交互（左键单击、悬停、滚轮）依赖全局鼠标钩子 `GlobalMouseService`，而它在**任何** `--ui-debug` 实例里都被硬性关闭（`AppStartupCoordinator.cs:213`，设计意图：debug 实例不得悄悄捕获用户输入，无开关）。所以人工 QA 只能用正常实例 + 临时替换真实配置来跑（先备份，验完还原）。

仓库根目录下的 PowerShell：

```powershell
# 1) 退掉正在跑的 Pulsar（避免它拿着缓存把配置写回去）
Get-Process Pulsar -ErrorAction SilentlyContinue | Stop-Process -Force

# 2) 备份你的真实配置（一次性；已备份过会覆盖同名备份，注意别拿备份当源）
Copy-Item "$env:APPDATA\Pulsar\Profiles.json" "$env:APPDATA\Pulsar\Profiles.json.bak-before-fan-qa" -Force

# 3) 装入 QA fixture
Copy-Item Pulsar\Pulsar.E2E\Fixtures\cascade-submenu-fan-qa.json "$env:APPDATA\Pulsar\Profiles.json" -Force

# 4) 正常启动（不加任何 --ui-debug 参数；detached 不卡终端）
Start-Process -FilePath "Pulsar\Pulsar\bin\Debug\net8.0-windows\Pulsar.exe" `
    -WorkingDirectory "Pulsar\Pulsar\bin\Debug\net8.0-windows"
```

**验完还原**（QA 结束后必做）：

```powershell
Get-Process Pulsar -ErrorAction SilentlyContinue | Stop-Process -Force
Copy-Item "$env:APPDATA\Pulsar\Profiles.json.bak-before-fan-qa" "$env:APPDATA\Pulsar\Profiles.json" -Force
Start-Process -FilePath "Pulsar\Pulsar\bin\Debug\net8.0-windows\Pulsar.exe" `
    -WorkingDirectory "Pulsar\Pulsar\bin\Debug\net8.0-windows"
```

> PowerShell 里 `copy` 是 `Copy-Item` 的别名，不展开 `%APPDATA%`，所以走 `Copy-Item + $env:APPDATA`。

- 起好后（托盘 Pulsar 图标），唤出轮盘确认加载到了三个格子：**QA Fan-2 / QA Fan-3 / QA Ring-5**。
- 日志核验（可选）：`%APPDATA%\Pulsar\Logs\pulsar-<日期>.log` 里应同时出现 `Hotkey service initialized` 和 `GlobalMouseService initialized.`（后者就是鼠标交互的开关）。
- 构建走 `.\scripts\dev.ps1 build` 就行（你正常 PowerShell 里 OK —— env 补丁、dotnet 解析它都自己做了）。
- （历史注记：曾尝试用 `Pulsar.Debug` 隔离配置跑 QA，发现 `--ui-debug` 连热键都不注册、`--ui-debug-hooks` 只救回热键救不回鼠标钩子，最终放弃隔离方案。教训见 journal 2026-09-05。）

**开始前必须做的一件事**：开一个空白记事本，在里面点一下（让光标闪着）。  
原因：每个子动作的效果就是「往当前窗口打一行字」，比如 `QA-2A`。你看到哪个标记，就知道刚才触发的是哪个子项。  
⚠️ 别停在正在写的文档或微信聊天框上唤出菜单 —— 菜单一关，字就打进去了。

**四个操作口诀**（后面一直用）：

| 想干什么       | 怎么干                               |
| ---------- | --------------------------------- |
| 叫出动作轮盘     | 按住 `Ctrl+Shift+Q` **不放**          |
| 展开某个格子的子动作 | **左键单击**那个格子（光把鼠标移上去没用）           |
| 执行子动作      | 移到子项上，**松开 `Ctrl+Shift`**（左键单击也行） |
| 退回外层轮盘     | **右键单击**，或点正中间的「返回」               |
| 子菜单里翻页     | 滚**滚轮**                           |

## A. 扇形：画得对不对（2.1）

- [ ] **A1 两个子项**：点开 `QA Fan-2` → 应该是 2 个小格子，一个偏上、一个偏下，像张开的剪刀，沿着父格子的方向往外伸（不是固定朝上）。`QA2-A` 在上、`QA2-B` 在下。
- [ ] **A2 三个子项**：点开 `QA Fan-3` → 3 个小格子排成「上 / 正前方 / 下」，中间那个正对着父格子的正前方。
- [ ] **A3 方向跟着父格子转**：三个父格子在轮盘的不同方位，各自展开的朝向应该各不相同 —— 都跟着自己父格子的方向，不能千篇一律。
- [ ] **A4 字看得清**：小格子上的名字（`QA2-A` 之类）没被切掉、没顶出轮盘边界。

## B. 扇形：点得准不准（2.2）

> 这一组是本轮**最关键**的：眼睛看到高亮在哪，松手后就得执行哪一个。

- [ ] **B1 指哪亮哪**：鼠标滑进某个子项，只有它亮，旁边的别跟着亮。
- [ ] **B2 松手只触发它一个**：停在 `QA3-B` 上松手 → 记事本只多出一行 `QA-3B`，**没有**隔壁的 `QA-3A` / `QA-3C`。至少抽查 4 个子项（`QA2-A`、`QA2-B`、`QA3-A`、`QA3-C`）。
- [ ] **B3 正中间那块是死区**：鼠标停在轮盘正中心松手 → 什么都不执行（退回外层或没反应都算对），记事本没新内容。
- [ ] **B4 太远也不该中**：鼠标拉到小格子最外圈**再往外**一点松手 → 不执行任何子项。
- [ ] **B5 左键单击也一样**：改成左键单击子项（不松修饰键），效果同上，只触发它一个。

## C. 4 个以上：应该自动变成小圆环（2.3）

- [ ] **C1 5 个子项变圆环**：点开 `QA Ring-5` → 因为超过 3 个，应该排成一圈**小圆环**（而不是扇形）。
- [ ] **C2 环带内外要对得上**：贴着圆环的内侧 / 正中 / 外侧各点一个子项，命中的都该是你看到的那个；离得太近（靠近中心）或太远（出了环）都不该命中。
- [ ] **C3 相邻不串台**：围着圆环慢慢转一圈，高亮切换的位置要和视觉分界一致 —— 不能出现「高亮的是 A、执行的是 B」。

## D. 分页叠加（2.4）

> 先换配置：`copy /Y Pulsar\Pulsar.E2E\Fixtures\cascade-submenu-fan-qa-paged.json %APPDATA%\Pulsar.Debug\Profiles.json`，然后重开调试实例。  
> **为什么要换**：子菜单一页放几个，跟外层轮盘共用同一个「每页槽位数」设置（默认 8）。5 个子项在默认设置下**一页就装完了，根本不会分页**，所以要把它调到最小值 4，才会变成 2 页（第 1 页 4 个、第 2 页 1 个）。

- [ ] **D1 能翻页**：点开 `QA Ring-5` → 滚轮可以在两页之间来回转。
- [ ] **D2 两层页码互不干扰**：在子菜单里翻页时，外层轮盘的页码不该跟着变；退出子菜单后，外层还停在你进去之前那一页。
- [ ] **D3 只能点到当前页的**：翻到第 2 页后，第 1 页那些子项**点不到**（哪怕它们还在原来的位置）。
- [ ] **D4 中心显示页码**：多于 1 页时，正中间会显示「第 x/y 页」。
- [ ] **D5 到头不回卷**：在第 1 页往前滚（或最后一页往后滚）→ 给个到头的提示就停住，**不要**绕回另一页。
- [ ] **D6 验完换回去**：把 `cascade-submenu-fan-qa.json` 重新拷回去，继续下面的用例。

## E. 深色 / 浅色都正常（2.5）

- [ ] **E1 深色**：设置 → 通用 → 外观 → 主题，切到 Dark → 重做 A1、A2、C1，看小圆环的描边、高亮、文字都还看得清（**不能出现白底白字、或深色底深色字**）。
- [ ] **E2 浅色**：切回 Light → 同样全部正常。
- [ ] **E3 立刻生效**：切完主题**当次**唤出轮盘就该变，不用重启。

## F. 高 DPI（150% 缩放）别跑偏（2.6）

- [ ] **F1 150% 下仍点得准**：系统显示缩放调到 150%（要注销重登才生效），重做 B2 和 C2 —— 命中的位置和眼睛看到的还是同一个。（这是本次要验证的核心假设：布局是纯几何算的，理论上跟像素密度无关。）
- [ ] **F2 无偏移**：同一个子项，在 100% 和 150% 下，鼠标停在它正中间都应该命中它。
- [ ] **F3 双屏不同缩放**（有条件就做）：把窗口拖到缩放比例不同的另一个屏幕上唤出，命中依然不偏。

## G. 往外一甩 = 整单取消（2.7）

> 背景注记：这一组曾因「`--ui-debug` 实例不注册鼠标钩子」一度标注为无法执行；后来整套 QA 改为真实配置的正常实例（见准备节），G 组恢复为**必测**。
>
> **操作前提（先做）**：设置 → 通用 → 右键拖拽 → 打开「右键拖拽唤出」开关（QA fixture 里这个开关默认是关的）。
> 动作轮盘的拖拽键是 `Shift`：按住 `Shift` 再按住**右键**拖一下，轮盘就出来。

- [ ] **G1 甩远了会变暗**：`Shift`+右键唤出 → 左键点开 `QA Fan-3` → 把鼠标往轮盘外面甩（超过大轮盘半径的 1.5 倍）→ 整个菜单**变暗**，意思是「松手就取消」。
- [ ] **G2 松手真的全取消**：这时松开右键 → 一个动作都不执行（记事本没新增），菜单干净关闭，没留下半截子菜单。
- [ ] **G3 甩多远按大轮盘算，不按小圆环算**：关键点是 —— 就算你人还在小圆环附近，只要离**大轮盘中心**够远，就算取消。不会出现「钻进子菜单后突然很难取消」。
- [ ] **G4 快捷键唤出的不受影响**：改用 `Ctrl+Shift+Q` 唤出，把鼠标甩到同样远 → 正常命中，**不会**触发取消（这个取消手势只对右键拖拽有效）。
- [ ] **G5 收尾**：验完把「右键拖拽唤出」关回默认。

## H. 别把老功能搞坏（2.8）

- [ ] **H1 窗口切换子菜单照旧**：开两个以上记事本 → `Ctrl+Q` 唤出切换轮盘 → 点那个分组格子 → 窗口子菜单跟以前一模一样（排布、点击、返回都正常）。
- [ ] **H2 普通格子照旧**：对**没有**子动作的普通格子，左键单击仍然直接执行它自己的动作，不会被子菜单逻辑抢走。
- [ ] **H3 直接松键 = 执行父格子自己**：鼠标停在带子动作的格子上，不点、**直接松开** `Ctrl+Shift` → 执行的是这个格子**本身**（打出 `QA-ROOT1` 之类），而不是展开子菜单。
